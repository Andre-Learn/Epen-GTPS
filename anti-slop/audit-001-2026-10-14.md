# antislop audit 001 (2026-10-14)

Scope: whole project (app/, components/, lib/, data/default-config.json, CSS). Read-only; nothing changed.
Not run: no node_modules, so no build/click-through yet (R-35 still open). Findings come from reading the code.
Contrast checked with antislop-human/contrast-check.py.

Priority: HIGH = Hard Gate, MEDIUM = Purpose-Gate, LOW = Quality Lock.

## HIGH

1. R-38 / R-17: Promote package "Skip All" price is `Rp??.000` (default-config.json). It looks like a placeholder but reads as a broken price. Fill in the real price, or show "Harga via Discord".
2. R-38: Partner links are bare roots: `https://wa.me/`, `https://discord.com/`, `https://youtube.com/` (Vincent, Dora). The buttons work but go nowhere useful. Use real links or leave them empty so the button is hidden.
3. R-38: Fallback videos are all `dQw4w9WgXcQ` (Rick Astley) with titles like "Video Epen GTPS #1" and "GTPS Community Update". If YouTube fails, visitors see fake titles on a rickroll. Use real video IDs or an empty list (the empty state already exists).
4. R-27: Video refresh fails silently (`youtube-client.js` returns null, only a console.warn). A 429 or 502 shows nothing. Add a short error line ("Gagal memuat ulang, coba lagi sebentar") next to the refresh button.
5. R-27: Home video grid has no empty state. If the feed and fallback are both empty, the "Video Epen GTPS" heading sits over nothing. Partner videos already have "Belum ada video".
6. R-25: Light mode `--muted #77717f` on `--bg #f7f6fa` is 4.38:1 and on `--surface-2 #f0edf5` is 4.07:1, both below 4.5. Used for kickers, captions, descriptions and the breadcrumb. Darken to about `#6b6573`.
7. R-25: White text on the light ends of purple gradients fails: `#fff` on `#8b5cf6` is 4.23:1 and on `#a78bfa` is 2.72:1 (default cover-art, partner banner "signature" right side, avatar fallback letter). The partner banner tagline is also at opacity .78. Keep text over the dark part of the gradient, or darken the gradient stops.
8. R-25 / R-03: Tiny text sizes in globals.css media queries (34 rules at 7.5 to 10px, e.g. `.profile-mini-copy small{font-size:7.5px}`, `.header-back{font-size:9px}`, theme-switch label 10px, FAQ 11px on mobile). Most are overridden by design.css, but the ones that aren't are unreadable on phones. Set a 12px floor.
9. R-03: Tap targets under 44px: refresh button 32px on mobile, modal close 36px, theme switch track 24px tall with 4px padding, `.header-back` about 30px on small screens, share buttons 42px. Increase the hit area (padding or min-height 44px).
10. R-32: `.server-search input{outline:0}`. The wrapper gets a `:focus-within` ring in design.css, so it's covered, but the rule is fragile. Keep it and note why, or move the focus style onto the input.
11. R-32: The server modal is hidden with `visibility` but not `inert`. While it's closed, the off-screen links inside it may still be in the accessibility tree because `aria-hidden` sits on a wrapper that contains focusable children. Add `inert={!selected}`.
12. R-02: Em dash in visible text: home H2 "Epen GTPS — Promoter Growtopia Private Server", 404 title, every page `<title>` and og:title (default-config, lib/servers.js, lib/server-seo.js, lib/metadata.js, OG image alt, JSON-LD names). Replace with `:`, `|` or `,`. Tab titles count as UI text.
13. R-35: Not verified. Run `npm install && npm run build`, then click through every control in light and dark mode at 360px and desktop: action cards, theme toggle, refresh, Show More/Less, server search, modal open/Escape/close, share copy/share, partner accordion, FAQ, promote CTAs, footer nav.

## MEDIUM

14. R-07 / R-01: Default cover art stacks a grid background (`.cover-grid`), a blurred glow, a radial "orb" with an "E", and a blue-purple gradient. It only shows when no banner is set, and you do set one, so it's mostly dead code. Delete it, or keep one gesture with a written reason.
15. R-07 / R-01: The partner template banner has the same stack (`partner-banner-template-grid`, glow, purple gradient). Both partners use it, so it's what visitors see on /partners. Pick one motif (e.g. the partner name set big on a flat brand purple).
16. R-10: Glass blur appears on the header (light mode), the modal backdrop, `.socials a`, and the original modal card (overridden). Keep it on the header only and drop it from `.socials` and the backdrop.
17. R-09: Promote "Populer" badge on "Skip" (the second of four). It's a real config flag, which is fine, but write down why Skip is the one to recommend (best value?). Otherwise it's the template "Most Popular" card.
18. R-08: The `›` chevron is on server cards, modal links, the "Lihat semua server ›" link and the breadcrumb. In lists it signals "opens", which is useful. Drop it from the inline text links.
19. R-06: The theme switch says "Light"/"Dark" and other UI text is English ("Show More", "Latest content", "Partner content", "Partner profile", "GTPS directory", "Made for the GTPS community.") on an Indonesian site with `lang="id"`. Pick Indonesian throughout.
20. R-04: Icons are PNGs recoloured with long CSS `filter` chains (`--icon-filter`). It works, but it's brittle in dark mode and blurry on high-DPI screens. Use inline SVG with `currentColor`, like `ActionIcon` already does.

## LOW

21. R-05 / R-28: The promote page is the template layout: hero, price cards, a "Cara kerja" 4-step numbered grid, FAQ, final CTA. The steps contradict each other (step 3 "Lakukan Pembayaran" says to contact via the order button, which is step 1). Merge into 3 honest steps, or fold them into the FAQ. The FAQ itself is product-specific, so it passes.
22. R-15: All four promote CTAs say "Pesan Sekarang" and go to the same Discord invite. Make them specific: "Pesan Normal via Discord", and so on, so the destination is clear before the tap.
23. R-16 / SEO: "GTPS Terbaru 2026" is stuffed into every server title, H1, description, FAQ and keyword list, and `mergeServersSeo` forces 2026 into stored titles. It reads like spam and will go stale in January. Make the year a single config value, or drop it from the H1s.
24. R-38: Every server description is the same "Growtopia private server terbaru 2026." Combined with the auto-generated "about" text, all detail pages are near-duplicates. Ask the server owners for one real line each (features, rates, event).
25. R-31: Two stacked stylesheets (globals.css 1,649 lines + design.css 783 lines that override it with 4 + 24 `!important`, "v6.4", "Perbaikan v2"). Dead classes remain (`.profile-mini`, `.theme-button`, `.footer-scene`, `.detail-banner`, skeleton). Merge into one file per concern and delete what's unused. This is maintenance, not visual.
26. R-21 / R-34: The dark theme is a solid set of overrides, but every component needs two rules. Move colours to tokens only (`--header-bg`, `--on-accent`) so dark mode is just a token swap.
27. C-4: The 404 page uses an inline `system-ui` style with no header, footer or theme. It's a dead end that looks off-brand. Reuse PageShell + SiteHeader.
28. C-1: The footer bottom "Made for the GTPS community." is filler. Replace it with something real (contact email, Discord) or remove it.

## Not slop (keep)
- Security: CSP, admin gate, rate limit, safeUrl sanitising, timing-safe compares. Well done.
- Server modal: focus trap, Escape, focus return, deep link, bottom sheet on mobile.
- No fake testimonials, stats, trust logos or buzzwords. FAQs are product-specific.
- prefers-reduced-motion respected; motion is one intro only.
- Maintenance/"Segera Tersedia" states with noindex.

## Small code notes (outside antislop)
- `VideoParts.js` uses `rel="noopener"` (fine), elsewhere `noopener noreferrer`. Make them consistent.
- `@vercel/blob: "latest"`: pin a version.
- `api/admin` cookie `secure: true` breaks admin login on http://localhost in dev; the middleware already uses NODE_ENV.
- `validConfig` checks `config.servers` and `config.promote`, but the real paths are `config.site.servers` and `config.site.promote`.
